# Nimbus Robotics: Engineering Onboarding

Every new engineer is paired with an onboarding buddy for their first 60 days. Buddies are assigned by the engineering manager before the start date.

## First week

On day one you receive a laptop, access to GitHub, and a Harbor portal account. The first-week checklist includes setting up the Atlas dev environment, shipping a small change to the `hello-robot` sample repo, and attending the Friday architecture review.

## Code review standards

All changes to the `atlas-core` repository require two approvals, and at least one reviewer must be on the owning team. Pull requests should stay under 400 changed lines; larger changes need a design doc linked in the description.

Production deploys happen on Tuesdays and Wednesdays only. There is a deploy freeze on Fridays.

## On-call

Engineers join the on-call rotation after 90 days. A rotation lasts one week, and on-call engineers receive a $400 stipend per week plus a comp day the following Monday.
